## Overview

**NABSHÉ** is a mobile-first digital sanctuary and boutique apothecary developed for an ultra-luxury Dubai wellness brand. The application merges centuries-old Middle Eastern beauty rituals (pure 24K cellular gold, rose damascena, authentic eucalyptus beldi hammam, and royal oud) with modern aesthetic techniques and white-glove concierge dispatch.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <repo-url>

# Install dependencies
npm install

# Start local development server (runs on port 3000)
npm run dev

# Build for production
npm run build
```
